# 밋앤잇 (Meet & Eat)

강원특별자치도교육청 업무 지원 장소 대시보드. 업무 목적(오찬 미팅, 팀 회식, 미팅 카페, 연수/대관)에 맞는 장소를 인원·가격·시설·행정서류 지원 여부로 검색.

- 기술 스택: Vite + React + TypeScript + Tailwind CSS + Lucide React
- 명세: `../gangwon-edu-dashboard-spec.md`

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 배포용 파일 생성
```

## 데이터 불러오는 순서

1. 구글 시트 (`src/config.ts` 의 `GOOGLE_SHEET_CSV_URL` 에 주소가 있을 때)
2. `public/data/venues.csv` (구글 시트를 못 읽을 때 쓰는 기본 데이터)

## 구글 시트 연동

1. 구글 드라이브에 `밋앤잇_장소리스트_구글시트용.csv` 를 올리고 구글 스프레드시트로 열기
2. `파일 → 공유 → 웹에 게시` → 형식을 `쉼표로 구분된 값(.csv)` 으로 선택 후 게시
3. 받은 주소를 `src/config.ts` 의 `GOOGLE_SHEET_CSV_URL` 에 붙여넣고 GitHub 에 올리기(push)
4. 이후에는 시트만 고치면 사이트에 반영 (구글 쪽 반영 지연 약 5분)

## 시트 작성 규칙

첫 행(열 이름)은 바꾸지 않기. 열 순서는 바꿔도 됨.

| 열 | 입력 방법 |
|---|---|
| 카테고리 | `식사` / `카페` / `연수·대관` |
| 상호명, 주소, 예약 전화번호, 최대 인원 | 필수 |
| 프라이빗 룸, 빔프로젝터, 전용 주차, 세금계산서, 견적서, 사업자등록증, 카드결제 | `Y` / `N` |
| 도교육청에서 차로(분) | 숫자만 (예: `6`) — 비우면 표시 안 함 |
| 1인당 가격(원) | 숫자 (예: `15000`) — 비우면 가격 필터에서 제외 |
| 최종 확인일 | 예: `2026-10-05` |
| 지도 링크 | 비우면 네이버 지도 검색 결과로 연결 |
| 번호, 세부 분류, 주요 인근 기관, 최소 인원, 검증 평점, 리뷰 수, 검증 후기 | 비워도 됨 |

웹에 게시한 시트는 주소를 아는 누구나 볼 수 있으므로 개인정보·내부자료는 넣지 않기.

## 배포 (GitHub Pages)

`main` 브랜치에 올리면(push) `.github/workflows/deploy.yml` 이 자동으로 빌드·배포.
저장소 `Settings → Pages → Source` 를 `GitHub Actions` 로 한 번 설정해야 함.
