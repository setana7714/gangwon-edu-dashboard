# 밋앤잇 디자인 키트

## 브랜드 한 줄
**바쁜 공공 업무를 위한, 믿고 고르는 춘천의 만남 장소 큐레이터.**

성격: **다정한 · 실무적인 · 살짝 장난스러운**

## 로고 콘셉트
- **지도 핀**: 교육청 인근 장소를 찾는 서비스라는 의미
- **웃는 얼굴**: 어렵고 딱딱한 행정 검색을 부드럽게 만든다는 의미
- **포크**: Meet & Eat의 식사·만남을 상징
- 심볼만 단독으로 쓰거나, 가로형 로고와 조합해 사용합니다.

## 컬러
| 이름 | HEX | 사용 |
|---|---|---|
| 밋 민트 | `#9CE6D3` | 핵심 브랜드 컬러, 선택 상태, 지도 핀 |
| 잇 코랄 | `#FF8368` | CTA, 추천 배지, 포인트 아이콘 |
| 딥 포레스트 | `#173B3F` | 본문, 헤더, 어두운 섹션 |
| 바닐라 크림 | `#FFF7E8` | 전체 배경, 카드 배경 |
| 세이지 그레이 | `#DDE8E3` | 구분선, 비활성 상태 |

**비율 가이드:** 크림 55% / 딥 포레스트 25% / 민트 15% / 코랄 5%

## 타이포그래피
- 한글: `Pretendard`, fallback `Apple SD Gothic Neo`, `Noto Sans KR`
- 큰 제목: 700–800, 자간 -0.04em
- 본문: 400–500, line-height 1.6
- 태그/뱃지: 700, 12–13px

## UI 시그니처
1. **말랑한 pill 태그**: 카테고리와 필터를 둥근 캡슐 형태로 표현
2. **핀-카드 조합**: 주소/거리 정보 앞에 작은 민트 지도 핀을 사용
3. **추천 픽 별 배지**: 평점이 높거나 행정서류 4종을 모두 지원하는 장소에 코랄 별 배지
4. **작은 얼굴 점 두 개**: 빈 상태, 로딩, 툴팁에 두 눈 + 미소를 최소 그래픽으로 반복

## 마이크로카피 예시
- 헤드라인: `오늘의 업무, 장소 고르기부터 가볍게.`
- 빈 상태: `음, 이 조건으로는 딱 맞는 곳이 없어요. 필터를 살짝 풀어볼까요?`
- CTA: `전화로 자리 확인하기` / `지도에서 살펴보기`
- 성공 피드백: `좋아요. 행정서류까지 챙기는 곳만 모았어요.`

## 파일 사용법
- `meetneat-logo.svg`: 헤더, 소개 페이지, 공유 이미지의 워드마크
- `meetneat-symbol.svg`: 파비콘, 모바일 헤더, 아바타, 앱 아이콘
- `meetneat-icons.svg`: 식사/카페/대관/추천 픽 카테고리 아이콘 스트립
- `meetneat-doodle-pattern.svg`: 섹션 하단, 빈 상태 배경, 푸터 띠 배경

## 안전 여백 및 크기
- 가로형 로고 사방에 심볼 높이의 0.5배 이상 여백
- 로고 권장 최소 폭: 디지털 136px, 인쇄 32mm
- 심볼 권장 최소 크기: 24px
- 로고 색상은 임의 변경하지 않고, 밝은 배경에는 기본형, 어두운 배경에는 심볼 외곽선을 유지한 반전형을 별도 제작해 사용
